# Практика бэкенда на Go

Один модуль для серии упражнений. Требуется Go 1.22 или новее. Для самостоятельной задачи добавляйте каталог с номером выпуска. Если упражнение развивает существующий сервис, продолжайте в его каталоге.

## № 1. Расчёт стоимости доставки

Реализуйте обработчик в `01-shipping-quote/handler.go`. Запрос `POST /v1/shipping/quote` принимает JSON с полями `zone` и `weight_grams`. Вес должен быть целым числом от 1 до 20 000 г. Стоимость в копейках возвращается в поле `price_kopecks` со статусом 200.

| Зона | Базовая стоимость | За каждый начатый килограмм |
| --- | ---: | ---: |
| local | 15 000 | 3 000 |
| remote | 30 000 | 6 000 |

Проверяйте метод, тип содержимого, затем тело. Принимайте `application/json` с параметрами. Для другого метода возвращайте 405 с заголовком `Allow: POST` и ошибкой `method_not_allowed`. Для неподходящего или отсутствующего типа содержимого возвращайте 415 с ошибкой `unsupported_media_type`. Возвращайте 400 с ошибкой `invalid_request` для некорректного JSON, неизвестных полей, нескольких JSON-значений и недопустимых зоны или веса. Ошибки передавайте в поле `error`. Ответы на этом маршруте имеют тип `application/json`.

## Запуск

```sh
go run ./01-shipping-quote
```

```sh
curl -i http://127.0.0.1:8080/v1/shipping/quote \
  -H 'Content-Type: application/json' \
  -d '{"zone":"local","weight_grams":1200}'
```

Заглушка вернёт 501. После реализации ожидается 200 с телом `{"price_kopecks":21000}`.

## Тесты

```sh
go test ./...
go test -tags=exercise ./01-shipping-quote
```

Первая команда запускает базовый тест маршрутизации. Вторая включает тесты контракта. Они будут падать, пока обработчик отвечает 501. Когда все сценарии проходят, можно удалить строку `//go:build exercise`, чтобы тесты контракта запускались вместе с остальными.

Для создания локального Git-репозитория выполните `git init` в распакованном каталоге. Имя модуля `example.com/go-backend-practice` можно заменить на адрес репозитория при публикации.
